## 📖 Описание программы
Графическое приложение для генерации случайных паролей. Позволяет настраивать длину и типы символов, копировать пароль в буфер обмена, а также сохраняет историю сгенерированных паролей в JSON.

### Возможности:
- ✅ Генерация паролей (цифры, буквы, спецсимволы)
- ✅ Настройка длины (4–32 символа)
- ✅ Выбор типов символов: цифры, буквы, спецсимволы
- ✅ Копирование пароля в буфер обмена
- ✅ Автоматическое сохранение истории в JSON
- ✅ Просмотр истории в таблице
- ✅ Очистка истории с подтверждением
- ✅ Обновление таблицы истории
